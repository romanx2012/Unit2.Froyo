Unit2.Froyo

This is a simple JavaScript project that asks the user to enter a list of froyo flavors using a prompt.  
It then counts how many of each flavor was ordered and displays the result in the browser console as a table.

How to Use
1. Open `index.html` in your browser using Live Server.
2. A prompt will appear asking for froyo flavors (separated by commas).
3. Enter something like: `vanilla,vanilla,strawberry,coffee,coffee`
4. Open the console (right click > Inspect > Console) to see the results.

Files
- `index.html` – basic web page
- `index.js` – JavaScript code to count froyo flavors
